Como funciona este ambiente

Atualizações no mesmo endereço

Envie versões atualizadas dos arquivos ao mesmo repositório GitHub; as páginas continuam com URLs fixas.

Teste com dados fictícios

Os logins dos protótipos não são autenticação real. Como o GitHub Pages é público, não cadastre produção, parceiros reais ou informações sigilosas.

Notícias no mesmo navegador

A Central e os portais podem compartilhar dados locais ao usar o mesmo domínio no mesmo navegador. Não há banco de dados compartilhado entre usuários.

Integrações externas

O Calendly recebe as reservas de Digitação. Outras integrações corporativas exigem backend, permissões e homologação.
